# Contributing

Use Node.js 22. Install all three lockfiles with `npm ci`, `npm ci --prefix server`, and `npm ci --prefix client`. Run `npm run build` and `npm test` before proposing changes.

Keep fixtures fictional and use example.com for contacts. Never commit environment files, database exports, operational documents, or generated passenger PDFs. Explain which backend a change affects and add meaningful regression coverage. Keep README claims aligned with the implemented behavior and recorded verification. Database behavior requires database tests; the demo suite alone is not sufficient.
